# Atividade de Pesquisa — Testes de Software

## Como executar o projeto

É necessário ter o Node.js instalado.

```bash
https://nodejs.org/en/download
```

Primeiro, abra o terminal dentro da pasta do projeto e execute:

```bash
npm install
```

Depois, para executar os testes:

```bash
npm test
```

Para abrir a aplicação no navegador:

```bash
npm start
```

Depois acesse:

```text
http://localhost:3000
